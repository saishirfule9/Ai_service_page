
# AI Service Page

This project is a single page landing website for an AI consulting business. It was built as part of an AI Developer challenge to demonstrate clean UI, responsiveness, and practical use of AI tools in development.

## Features
- Professional AI consulting landing page
- Fully mobile responsive design
- Working contact form using Formspree
- Clean and simple UI focused on clarity

## Tech Stack
- HTML
- CSS
- JavaScript
- Formspree (contact form)
- GitHub Pages (hosting)
